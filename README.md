# 历史背诵助手 PWA
 
一个用于背诵历史知识的闪卡应用。
 
## 功能
 
- 历史知识闪卡
- 搜索知识点
- 按朝代筛选
- 添加自定义卡片
- 导入/导出数据
- 标记掌握程度
- 支持键盘快捷键
- 支持 PWA 安装
- 支持离线使用
 
## 在线访问
 
https://github.com/LuDezi/history-flashcard-pwa/
 
## 使用方式
 
使用 Chrome 或 Edge 打开链接，可以直接使用，也可以安装为桌面应用。
 
## 数据说明
 
应用数据保存在浏览器 localStorage 中。  
不同用户之间数据不会自动同步。  
可以通过导入/导出 JSON 的方式共享卡片。
